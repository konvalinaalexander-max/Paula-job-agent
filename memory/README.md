# Gedächtnis

Diese Dateien sind das, was zwischen zwei Läufen erhalten bleibt und wodurch das
System besser wird. Jede Session liest sie zu Beginn und schreibt sie am Ende
fort. Begründung: [`docs/14-arbeitsweise.md`](../docs/14-arbeitsweise.md).

| Datei | Inhalt |
|---|---|
| `LERNTAGEBUCH.md` | Was funktioniert hat, was nicht, was daraus folgt. Datiert, fortlaufend |
| `suchstrategie.md` | Aktuelle Suchbegriffe mit Begründung, was noch auszuprobieren ist |
| `marktwissen.md` | Muster über den österreichischen Stellenmarkt |
| `textwissen.md` | Was in Bewerbungsbriefen ankommt |
| `experimente.md` | Laufende Versuche: Hypothese, Aufbau, Ergebnis |
| `offene-faeden.md` | Wofür gerade keine Zeit war |

## Die eine Regel

**Hier steht Wissen, keine Personendaten.**

Erlaubt: „Briefe unter 160 Wörtern bekommen häufiger Antwort." · „Baufirmen im
Bezirk X antworten selten." · „Der Begriff ‚Backoffice' bringt andere Treffer als
‚Assistenz'."

Nicht erlaubt: Firmennamen in Verbindung mit Paulas Bewerbungen, Mailadressen,
Namen von Personen, Bewerbungstexte, Auszüge aus ihren Mails. Das alles gehört in
die Dashboard-Datenbank, nie ins Repository.

Anonyme Muster über *Branchen* und *Regionen* sind Wissen und gehören hierher.
Eine einzelne Firma in Verbindung mit einer einzelnen Bewerbung ist ein Datum und
gehört es nicht.
